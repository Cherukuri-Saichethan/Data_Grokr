# Week 1 Mini Project - CLI Grade Calculator

## Description

A simple command-line Grade Calculator developed using Python.

The program accepts marks for multiple subjects, calculates the total marks and average, and assigns a grade based on the average score.

## Features

- Accepts marks for multiple subjects
- Calculates total marks
- Calculates average marks
- Assigns grades automatically
- Displays a complete grade report
- Uses Python functions, loops, and dictionaries

## Technologies Used

- Python

## Concepts Used

- Functions
- Loops
- Dictionaries

## How to Run

```bash
python3 grade_calculator.py
