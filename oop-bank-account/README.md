# OOP Bank Account

A simple banking system developed using Python OOP.

## Features

- Deposit money
- Withdraw money
- Check balance
- View transaction history
- Analyze transactions using pandas

## Technologies

- Python
- OOP
- pandas
- CSV

## Project Structure

- bank_account.py - Banking system
- transactions.csv - Transaction dataset
- analysis.py - Pandas analysis

## Run

python bank_account.py

## Analysis

python analysis.py
