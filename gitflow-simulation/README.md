# Gitflow Simulation

## Overview

A practical project demonstrating Git version control and the Gitflow branching strategy.

## Objectives

* Practise feature branches and pull requests.
* Understand merge commits and merge conflicts.
* Simulate release and hotfix workflows.
* Implement Git hooks for automated checks.
* Configure GitHub Actions for continuous integration.

## Technologies

* Git
* GitHub
* Python
* pytest
* GitHub Actions

## Project Status

Initial development.

## Gitflow Strategy

* `main`: stable production code
* `develop`: integration branch
* `feature/*`: new features
* `release/*`: release preparation
* `hotfix/*`: urgent production fixes

## Planned Workflow

Feature development → Pull Request → Merge → Release → Hotfix → Merge back into main and develop.
